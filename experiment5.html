Document Structure

<html>
The root element of an HTML document. All other elements are contained within this.
<html lang="en">...</html>
<head>
Contains meta-information about the document, such as its title and links to scripts and stylesheets.
<head><title>My Page</title></head>
<body>
Contains the visible content of the HTML document.
<body><h1>Hello World</h1></body>
<div>
A generic container for flow content with no semantic meaning.
<div class="container">Content here</div>

Text Content

<h1> to <h6>
Heading elements, with <h1> being the highest level and <h6> the lowest.
<h1>Main Heading</h1>
<h2>Subheading</h2>
<p>
Defines a paragraph of text.
<p>This is a paragraph of text.</p>
<span>
A generic inline container for phrasing content.
This is <span style="color:red">red text</span>.
<strong>
Indicates that its contents have strong importance.
This is <strong>important</strong> text.
<em>
Marks text that has stress emphasis.
I <em>really</em> mean it.
<ul> and <ol>
Unordered (bulleted) and ordered (numbered) lists.
<ul>
  <li>Item 1</li>
  <li>Item 2</li>
</ul>
<li>
Defines a list item within <ul>, <ol>, or <menu>.
<li>List item</li>

Multimedia

<img>
Embeds an image into the document.
<img src="image.jpg" alt="Description">
Common attributes: src, alt, width, height
<audio>
Embeds sound content in the document.
<audio controls>
  <source src="audio.mp3" type="audio/mpeg">
</audio>
<video>
Embeds a media player for video playback.
<video width="320" height="240" controls>
  <source src="movie.mp4" type="video/mp4">
</video>

Forms & Input

<form>
Represents a document section containing interactive controls.
<form action="/submit" method="post">...</form>
<input>
Creates interactive controls for forms.
<input type="text" name="username" placeholder="Enter username">
<input type="password" name="password">
<input type="email" name="email">
Common types: text, password, email, checkbox, radio, submit
<textarea>
A multi-line plain-text editing control.
<textarea rows="4" cols="50">Default text</textarea>
<select>
Represents a control that provides a menu of options.
<select name="cars">
  <option value="volvo">Volvo</option>
  <option value="saab">Saab</option>
</select>
<button>
A clickable button that can submit forms or trigger JavaScript.
<button type="submit">Submit</button>

Semantic HTML

<header>
Represents introductory content, typically a group of introductory or navigational aids.
<header><h1>Website Title</h1></header>
<nav>
Represents a section of a page whose purpose is to provide navigation links.
<nav>
  <a href="/home">Home</a>
  <a href="/about">About</a>
</nav>
<main>
Represents the dominant content of the <body> of a document.
<main><h1>Main Content</h1></main>
<article>
Represents a self-contained composition in a document.
<article><h2>Blog Post Title</h2></article>
<section>
Represents a standalone section of content.
<section><h2>Introduction</h2></section>
<aside>
Represents a portion of a document whose content is only indirectly related.
<aside><p>Related information</p></aside>
<footer>
Represents a footer for its nearest sectioning content or root element.
<footer><p>Copyright 2023</p></footer>

Tables

<table>
Represents tabular data in a table with rows and columns.
<table>
  <tr>
    <th>Name</th>
    <th>Age</th>
  </tr>
</table>
<tr>
Defines a row of cells in a table.
<tr><td>Data</td></tr>
<td>
Defines a cell of a table that contains data.
<td>Cell data</td>
<th>
Defines a cell as a header of a group of table cells.
<th>Column Header</th>

Interactive Elements

<a>
Creates a hyperlink to web pages, files, email addresses, or locations in the same page.
<a href="https://example.com">Visit Example</a>
<details>
Creates a disclosure widget in which information is visible only when the widget is toggled open.
<details>
  <summary>More Info</summary>
  <p>Hidden content revealed when clicked.</p>
</details>
<dialog>
Represents a dialog box or other interactive component.
<dialog open>
  <p>This is a dialog box</p>
</dialog>

Metadata

<title>
Defines the document's title that is shown in a browser's title bar or a page's tab.
<title>My Web Page</title>
<meta>
Represents metadata that cannot be represented by other HTML meta-related elements.
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, initial-scale=1.0">
<meta name="description" content="Page description">
<link>
Specifies relationships between the current document and an external resource.
<link rel="stylesheet" href="styles.css">
<style>
Contains style information for a document or part of a document.
<style>
  body { font-family: Arial; }
</style>
<script>
Used to embed or reference executable code, typically JavaScript.
<script>
  console.log('Hello World');
</script>
